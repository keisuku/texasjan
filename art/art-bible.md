# MAHJONG HOLD'EM — アートバイブル

このファイルの数値は全て `claude-handoff/visual/golden-target.webp`（941×1672）と
`claude-handoff/visual/sample-9pin.png`（76×88、Golden Visualから切り出した実物の牌）から
**実測したもの**です。推定値や好みは入っていません。新しい素材は全てこの数値に合わせてください。

計測方法: Chromium の canvas に原寸で描画し、`getImageData` で走査。再現用スクリプトは
`art/measure.html`（Phase 0で追加）。

## 2. 牌（最重要）

牌には**2つの姿**があります。モックが両方を描き分けているので、素材も2種類必要です。

| 用途 | 実寸(941幅換算) | アスペクト | 備考 |
|---|---|---|---|
| 卓上に伏せ気味に置かれた牌（共通15・私牌8・+4） | 65 × 73 | **1 : 1.123** | 遠近で潰れている |
| 手元に立てた牌（最終手牌13＋ツモ） | 62 × 115 | **1 : 1.85** | 正面向き |

### 2.1 シルエット（`sample-9pin.png` 実測）

- アルファのバウンディングボックス: **65 × 73**、内部は全て `alpha=255`（縁のぼかし無し）
- **角丸半径 ≈ 4px（幅の 6.2%）** — 左端の食い込みが上から `3, 2, 1, 0, 0…` と減衰
- 接地影はアルファに焼き込まれていない。影は**シルエット内部の暗い面取り**として表現されている

### 2.2 明暗プロファイル（縦断面 x=中央、輝度0-255）

```
行 0        : 252   ← 上端1pxの鏡面リム（最も明るい）
行 1–9      : 201–213
行 10–56    : 205–224（牌面。中央がわずかに明るい）
行 57–64    : 195–212
行 65–72    : 179 → 147 → 119 → 105 → 98 → 92 → 50 → 28   ← 下端の面取り
```

**下端 8px（高さの11%）が牌の厚み**です。ここが輝度179から28まで落ちることで実体が出ます。
CSSの `box-shadow: 0 Npx 0 色` のような単色オフセットでは絶対に出ない階調です。

横断面は左端1pxが暗く（輝度165）、本体は210–224でほぼ均一、x=8とx=53付近に輝度228/237の
鏡面バンドがあります。左上から光が入り、面がわずかに湾曲した円筒状の反射です。

### 2.3 象牙のカラーランプ

| 役割 | 色 | 出典 |
|---|---|---|
| 上端の鏡面リム | `#FFFDF1` | sample y=4 |
| 牌面ハイライト | `#FDE6D7` | 本体モック 最終手牌 y=1220 |
| 牌面 明部 | `#F2E3D7` / `#F0EBE2` | sample 横断面 |
| 牌面 基準色 | `#E1D1C2` | 本体モック |
| 牌面 中間 | `#DFD1C4` / `#DDCFBF` | 本体モック |
| 縁の陰 | `#CCC3B3` / `#D5BFAF` | 左リム |
| 下端 面取り上部 | `#735F4D` | y=1274 |
| 下端 面取り下部 | `#594D41` → `#1A1410` | y=1280以降 |

**現行実装の何が違うか**: 今の `index.html` は `linear-gradient(165deg,#FBF4E2,#EFE3C6,#DCCCA5)` の
3段グラデ＋`box-shadow` 一本です。鏡面リムも、湾曲した反射も、8pxの階調のある面取りもありません。
そこが「安っぽさ」の実体です。

### 2.4 牌面の意匠

`claude-handoff/visual/traditional-tile-reference.jpeg` が意匠の基準。
`sample-9pin.png` の九筒は、**赤い輪 + 濃紺の芯 + 白の抜き**の3層構造です（現行実装の単色塗りとは別物）。

牌面34種はベクターで作ります（Phase 3、私が担当）。**生成AIには依頼しません** —
34種の字画とピップ配置が1点でもぶれると破綻するためです。素材として必要なのは
**面が無地の牌体**だけで、それを136回使い回します。

## 3. 金のマテリアル

### 3.1 POTプレート（x328-607, y215-349）実測

外側から内側への横断面（y=280、左端）:

```
#EBBB92 → #FFFFD8 → #AC6E38 → #8D5A39 → #653612 → #4B1D03 → #946843 → #200000
→ #5C370F → #744911 → #F9C691（内側の面）→ #E8B586 → … → #D8A677
```

構造は **明るい外リム(#FFFFD8) → 暗い茶の縁取り帯 約8-10px(#4B1D03〜#653612) → クリーム色の内面(#F9C691→#D8A677)**。

縦のランプ（x=400）: 上端 `#FFEBCC` → `#EDD2B2` → `#EBCCA9` → `#E8C39B` → `#E1BA93` と落ち、
下端に `#734E2B` → `#884B0E` → `#CB9F6E` の立体リム。

### 3.2 金リボン（COMMON 15 ラベル、y381-415）

```
y382 #DAD5C7  ← 上端の細い明リム
y384–390 #060F00 〜 #021108  ← 内部はほぼ黒
y392 #FEFACB  ← 文字のハイライト
y394–406 #D8CB90 → #C19755  ← 文字本体の金
y408–412 暗部に戻る
```

**暗い地に金の文字**が正解で、金地に暗い文字ではありません。

### 3.3 ボタン（y1471-1636、ダイヤルのみ y1451-1649）

| ボタン | 上端リム | 面の上 | 面の下 | 下端リム |
|---|---|---|---|---|
| FOLD | `#BC854F` | `#B82915` | `#580C01` | `#EEC89A` |
| CALL | `#E6D6B7` | `#64CFFF`(鏡面) → `#0D7CE0` | `#012B6A` | `#FEE0C8` |
| RAISE | `#F6D5B5` | `#FED4A0` → `#F09A33` | `#8A4B0F` | `#FFF9E8` |
| ダイヤル | `#FFFFE1` | 紺 `#020C24` | `#00060E` | `#FFFFEB` |

全ボタンに共通する構造:
1. 太い金のリムが**上下にある**（下端リムは特に明るい `#EEC89A`〜`#FFF9E8`）
2. 面は上が明るく下が暗い縦グラデ
3. CALLだけ最上部に `#64CFFF` のガラス質の鏡面が乗る
4. ダイヤルは**紺の円盤を厚い金環が囲む**構造

### 3.4 フェルト

卓面: `#183824` / `#152E21` / `#162F24` / `#183625` — 平均 **`#16311F`** 付近。
均一ではなく微細なノイズがあります。

## 4. 光源

全素材で統一します。

- **方向: 左上（約 315°）からの主光源**
- 上端に細い鏡面リム、下端に厚い面取りと影
- 素材ごとに光源角度が違うと、並べた瞬間に破綻します

## 5. 品質ゲート
