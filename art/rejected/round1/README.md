# 不合格素材 round 1（牌3点）

2026-08-10 の納品分のうち、牌3点はここへ退避しています。ゲームでは使っていません。
**再生成したものは `assets/ui/` へ置いてください**（このフォルダではありません）。

## なぜ落ちたか

実測した defect は以下の2点です。「もっと綺麗に」ではなく、この2点が直れば合格します。

| 項目 | 実物 `claude-handoff/visual/sample-9pin.png` | この納品物 |
|---|---|---|
| 縁から面の明るさに到達するまでの距離 | 1–2px（**幅の2%以下**） | **幅の10%** |
| 面の輝度の起伏 | 198–224（**幅26**の緩やかな modelling） | 209–211（**幅3**＝完全な平坦） |
| 角丸半径 | 幅の6.2% | flat 6.9%（可）/ upright **10.9%**（過大） |

つまり **丸みを帯びた塊になっていて、平らな面を持つ板になっていない**。
そのため石鹸や角丸キューブのように見えます。

寸法・アスペクト比・透過・下端の面取りの階調（177→16）は全て合格でした。そこは変えないでください。
