# V2 Product-Screen Archive

This directory preserves the broad 18-screen exploration that preceded the Clean Masters.

The set expanded the project beyond one match screen into title, lobby, mode selection, characters, gacha, customization, shop, progression, events, tournament, and match drama.

Recorded verdict:

- KEEP: 01, 05, 07, 08, 10, 11, 13, 14, 15, 16, 17, 18
- MIX: none
- DROP: 02, 03, 04, 06, 09, 12

The entire set was later criticized for excessive AI-like detail (“gabigabi”), including hidden wave/ribbon language and over-rendered backgrounds. It remains useful for composition and feature coverage, but its surface density is not the production target.

The three Clean Masters were created as the correction.
