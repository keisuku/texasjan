# 仕様書: 牌体スプライト（最優先）

`tile-body-flat.png` / `tile-body-upright.png`

この2枚がこのプロジェクトで**最も重要な素材**です。画面には常時40〜60枚の牌が出ており、
その質感が画面全体の印象を決めます。時間をかける価値があるのはここです。

数値の出典は全て `art/art-bible.md`（完成見本からの実測）。

---

## 共通の要件

- PNG / **背景は完全な透明**（透過不可のツールでは `#FF00FF` ベタ塗り）
- **牌面には何も描かない。完全な無地。** 文字・ピップ・ロゴは全てコード側で載せます
- 光源は**左上**（約315°）
- 影を画像の外へ落とさない。牌のシルエットの内側だけで立体を表現する
- アルファの縁はぼかさない（実測でも内部は全て `alpha=255`）

## 材質

象牙。乳白色でわずかに黄味と赤味を含み、**まったく平坦ではなく、面がかすかに湾曲して光を返す**。
プラスチックのような均一なつやではなく、古い牌のような柔らかい艶。

## 1. `tile-body-flat.png` — 卓上の牌

- **260 × 292 px**（実使用 65 × 73、4倍で作成）
- アスペクト **1 : 1.123**
- 卓にやや伏せ気味に置かれ、上から見下ろした角度。遠近で縦に潰れて見える
- **角丸半径 = 幅の 6.2%**（260px幅なら 16px）

### 明暗の配分（画像の高さを100%としたときの実測プロファイル）

```
  0%          上端1px相当に鏡面リム #FFFDF1（輝度252）
  1% –  12%   #E8DAC9 付近（輝度 201–213）
 13% –  77%   牌面本体 輝度 205–224。中央がわずかに明るい
 78% –  88%   輝度 195–212
 89% – 100%   ★ 牌の厚みの面取り
              輝度 179 → 147 → 119 → 105 → 98 → 92 → 50 → 28 と階調をつけて落とす
              色は #735F4D → #594D41 → #1A1410
```

**下端11%の面取りが最重要です。** ここを単色のベタや単純なドロップシャドウで済ませると、
現在のCSS実装と同じ安っぽさになります。8段階の階調をつけてください。

横方向は左端1pxがわずかに暗く（輝度165）、本体は210–224でほぼ均一。
幅の12%と82%あたりに輝度228/237の弱い鏡面バンドが入り、面の湾曲を示します。

## 2. `tile-body-upright.png` — 手元に立てた牌

- **248 × 460 px**（実使用 62 × 115、4倍で作成）
- アスペクト **1 : 1.85**
- 正面から見た姿。伏せ気味ではなく、牌面がまっすぐこちらを向いている
- **`tile-body-flat.png` と同一の材質・カラーランプ・光源**を使ってください。
  並べたときに材質が違って見えると破綻します
- 下端の面取りは flat より薄く見えます（正面向きのため）。高さの 6〜8% 程度
- 角丸半径は幅の 6.2%（248px幅なら 15px）

## NG例

- 牌面に文字や絵柄が入っている
- 面取りが単色のベタ、または階調が3段以下
- 画像の外にドロップシャドウが出ている（背景と合成したときに黒い縁が出ます）
- 光源が右上・正面・下からになっている
- 白すぎる（`#FFFFFF` に近い）。象牙は `#E1D1C2` が基準です
- 表面がプラスチック的につるつるしている
- 2枚の材質・色温度が食い違っている

## 検査項目

`art/verify.html` で以下を自動チェックします。

1. 寸法とアスペクト比
2. アルファのバウンディングボックスが画像いっぱいに広がっているか（余白が多すぎないか）
3. 縦の輝度プロファイルが上記の配分と一致するか（特に下端の面取りの階調）
4. 主要色がアートバイブルのパレットから外れていないか（ΔE）
5. `flat` と `upright` の色温度が一致しているか
