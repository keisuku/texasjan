# 仕様書: 金枠パネル（9スライス）

`frame-gold-plate.png` / `frame-seat-plate.png` / `frame-group.png`

いずれも**9スライスで引き伸ばして使います**。四隅の装飾が中央部の引き伸ばしに
巻き込まれない構図にしてください。中央部は縦横に伸びても破綻しない、単調な面にします。

## 1. `frame-gold-plate.png` — POTプレート

- **560 × 268 px**（実使用 280×134）／透明背景
- 9スライス: 左64 / 右64 / 上72 / 下80
- 完成見本の実測（外→内）:
  ```
  #EBBB92 → #FFFFD8（明るい外リム） → #AC6E38 → #8D5A39 → #653612 → #4B1D03（暗い茶の縁取り帯 8-10px相当）
  → #946843 → #5C370F → #744911 → #F9C691（内面）→ #E8B586 → #D8A677
  ```
- 縦は上 `#FFEBCC` から下 `#E1BA93` へ落ち、下端に `#734E2B` → `#884B0E` → `#CB9F6E` の立体リム
- **中央の内面は数字が乗るので、装飾を入れず平坦に**

## 2. `frame-seat-plate.png` — 席の持ち点プレート

- **320 × 96 px**（実使用 160×48）／9スライス: 左40 / 右40 / 上24 / 下28
- 暗い地（`#092016` 付近）に**細い金枠**。POTプレートより地味に、控えめに
- 完成見本の各キャラクター下の「3,940」等の板が実物

## 3. `frame-group.png` — +4 グループ枠

- **500 × 664 px**（実使用 125×166）／9スライス: 左48 / 右48 / 上40 / 下72
- 暗い地（`#021E19` → `#010F0C`）に金枠。下部にラベル用の帯（下スライスが72pxなのはこのため）
- 中に伏せ牌が2×2で入ります
