# 仕様書: UIフレームのSVG構築（round 3）

**まず `art/ui-geometry.md` を読んでください。** 角丸比・縁の5層・光源はそこで共有仕様として
決まっています。この文書は部品ごとの寸法と色だけを定めます。

納品先は `assets/ui/svg/`。**`index.html` は編集しないでください**（実装側が編集中です）。

---

## 共通の必須事項

- `viewBox` はデザイン座標の実寸。`width`/`height` 属性は付けない（CSSで制御するため）
- `#rim` `#face` `#gloss` `#press` の4つのIDを必ず持たせる（`art/ui-geometry.md` 第6節）
- 縁は5層。2段グラデーション不可
- 光源315°固定
- 外部フォント・外部画像を参照しない。単独で完結すること
- 文字を一切入れない（実装側で描画します）

## 1. ボタン3種

| ファイル | viewBox | 面の上 | 面の下 |
|---|---|---|---|
| `btn-fold.svg` | `0 0 216 166` | `#B82915` | `#580C01` |
| `btn-call.svg` | `0 0 220 166` | `#0D7CE0` | `#012B6A` |
| `btn-raise.svg` | `0 0 227 166` | `#FED4A0` → `#F09A33` | `#8A4B0F` |

- 角丸半径 **50px**（高さの30%）。3つとも同じ値
- 縁の帯 **20px**（高さの12%）
- **CALLのみ**、面の最上部に `#64CFFF` のガラス質の鏡面を細く入れる（`#gloss` の中）
- `#press`: 内側の上部に暗い影、下部に淡い光。既定 `opacity:0`

## 2. `frame-gold-plate.svg` — POTプレート

- `viewBox="0 0 280 135"` / 角丸 **30px** / 縁の帯 **13px**
- 面はクリーム。上 `#F9C691` → 下 `#D8A677`
- **中央は数字が乗るので装飾を入れず平坦に**

## 3. `frame-seat-plate.svg` — 席の持ち点プレート

- `viewBox="0 0 160 48"` / 角丸 **10px** / 縁の帯 **5px**
- 面は暗い緑 `#092016`。金枠は細く控えめに（POTプレートより地味に）

## 4. `frame-gold-ribbon.svg` — 見出しリボン

- `viewBox="0 0 320 56"` / 角丸 **13px** / 縁の帯 **6px**
- 面は暗い緑 `#0C2C24`
- **両端に菱形の飾り**を付ける。実装側は横に2.1倍まで引き伸ばすので、
  飾りは左右それぞれ **端から40px以内** に収め、中央部（40px〜280px）は装飾のない単調な帯にすること
- これは9スライスで伸ばします。中央が伸びても破綻しない構図が必須

## 5. `frame-group.svg` — +4グループ枠

- `viewBox="0 0 125 166"` / 角丸 **10px** / 縁の帯 **8px**
- 面は暗い緑 `#021E19` → `#010F0C`
- 下部に高さ18pxのラベル帯（実装側が「+4 I」等を描きます。**文字は入れない**）
- 中に伏せ牌が2×2で入るので、中央は平坦に

## NG例

- 縁が2層以下、またはグラデーション1本で済ませている
- 部品ごとに角丸比が違う
- 光源が部品ごとに違う（上端が暗く下端が明るい、など）
- 文字が入っている
- `width`/`height` 属性が付いていて拡大縮小できない
- リボンの中央部に装飾があり、引き伸ばすと歪む

## 検査

`art/verify-ui.html` をブラウザで開くと自動判定します。
viewBox・角丸比・縁の層数・光源の向き・必須IDの有無を検査し、
落ちた項目は実測値と目標値を並べて表示します。
