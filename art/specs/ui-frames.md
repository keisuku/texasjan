# 仕様書: UIフレームのSVG構築（round 3）

**まず `art/ui-geometry.md` を読んでください。** 角丸比・縁の5層・光源はそこで共有仕様として
決まっています。この文書は部品ごとの寸法と色だけを定めます。

納品先は `assets/ui/svg/`。**`index.html` は編集しないでください**（実装側が編集中です）。

---

## 共通の必須事項

- `viewBox` はデザイン座標の実寸。`width`/`height` 属性は付けない（CSSで制御するため）
- `#rim` `#face` `#gloss` `#press` の4つのIDを必ず持たせる（`art/ui-geometry.md` 第6節）
- 縁は5層。2段グラデーション不可
- 光源315°固定
- 外部フォント・外部画像を参照しない。単独で完結すること
- 文字を一切入れない（実装側で描画します）

## NG例

- 縁が2層以下、またはグラデーション1本で済ませている
- 部品ごとに角丸比が違う
- 光源が部品ごとに違う（上端が暗く下端が明るい、など）
- 文字が入っている
- `width`/`height` 属性が付いていて拡大縮小できない
- リボンの中央部に装飾があり、引き伸ばすと歪む

## 検査

`art/verify-ui.html` をブラウザで開くと自動判定します。
viewBox・角丸比・縁の層数・光源の向き・必須IDの有無を検査し、
落ちた項目は実測値と目標値を並べて表示します。

# round 3 の結果と、round 4 でお願いしたいこと

## 結果: 幾何は合格、質感が足りない

納品された7点は `art/verify-ui.html` の判定を**全て通りました**。
特にボタン3種の角丸が全て 50px で一致しており、Golden Visual 自身が 53/47/49 と
ばらついていたことを考えると、**モックより揃っています**。狙い通りです。

しかし Golden Visual と並べて比較した結果、**金の質感が生成PNG版に負けていました**。
そのため既定は現状PNGのままとし、SVGは `index.html?svg=1` で切り替えて比較できる状態で
リポジトリに残しています。捨ててはいません。

## 何が足りないか

縁の層数は満たしていますが、**各層が単調**です。Golden Visual の金は、
同じ帯の中で輝度が 103→143→130→59→23→58→181 と細かく上下しています。
納品物は層ごとにほぼ一定の色で塗られており、そのため薄く見えます。

round 4 でお願いしたいのは以下です。**形は変えないでください。合格しています。**

1. **金リム本体（層2）の中に鏡面のゆらぎを入れる。** 一定のグラデーションではなく、
   帯に沿って明暗が2〜3回うねる。`art/ui-geometry.md` 3.1 の実測値の通り
2. **面の縁に内側の発光を足す。** 面が縁に接するところで少し明るくなる（1〜2px相当）
3. **上端の鏡面を強くする。** 現状は控えめ。Golden Visual は上端に強い白い筋がある
4. **面のグラデーションに周辺減光を足す。** 現状は素直な縦グラデ。
   中央がやや明るく四隅が沈むと厚みが出る

角丸・viewBox・縁の層数・光源・必須IDは合格しているので、そのまま維持してください。
