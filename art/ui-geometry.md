# UI幾何の共有仕様

**全部品がこの数値を共有します。** 部品ごとに違う値を使わないでください。
「揃って見える」ことの実体は、角丸比・縁の層構造・光源角度が全部品で同一であることです。

数値は `claude-handoff/visual/golden-target.webp`（941×1672）からの実測です。
色は `art/art-bible.md` の実測パレットを使います。

---

## 1. 座標系

各SVGの `viewBox` は **941×1672 のデザイン座標での実寸** を使います（4倍などにしない）。
例: FOLDボタンは `viewBox="0 0 216 166"`。ベクターなので拡大縮小は自由です。

## 2. 角丸半径 — 1つの値に固定する

Golden Visual の実測は FOLD 53px / CALL 47px / RAISE 49px（幅の21.4〜24.5%）で、
**同一部品なのに±6pxばらついています。** モック自体が揃っていません。
SVG化では以下に固定してください。

| 部品 | 角丸半径 |
|---|---|
| ボタン3種 | **高さの30%**（166px高なら 50px） |
| POTプレート | 高さの22%（135px高なら 30px） |
| 席プレート | 高さの20% |
| リボン | 高さの23%（35px高なら 8px） |
| +4グループ枠 | 幅の8% |

## 3. 縁の層構造 — 仕様の核心

**縁は必ず5層です。2段グラデーションは不可。** ここを省くと、どれだけ色を合わせても平坦に見えます。

### 3.1 ボタン（実測: FOLD上端 x=124、縁の帯は約20px = 高さの12%）

外側から内側へ。括弧内は実測輝度。

| # | 層 | 幅 | 輝度 | 役割 |
|---|---|---|---|---|
| 1 | 外側の明線 | 1px | 160 | 金の最外郭 |
| 2 | 金リム本体 | 9px | 103–143 | **内部に鏡面のゆらぎを持たせる**（一定値にしない） |
| 3 | 暗い分離線 | 4px | 59 → 23 | リムと面を切る。ここが効く |
| 4 | 内側の明るいベベル | 6px | 58 → 181 | 面へ立ち上がる光 |
| 5 | 面 | 残り | 各色 | 上が明るく下が暗い縦グラデ |

縁の帯の幅は **高さの12%**（166px高なら 20px）で固定します。

### 3.2 プレート・枠（実測: POTプレート左端 y=280、縁の帯は13px）

| # | 層 | 幅 | 輝度 |
|---|---|---|---|
| 1 | 暗い外線 | 1px | 38 |
| 2 | 明るいベベル | 4px | 112（頂点） |
| 3 | 暗い谷 | 2px | 9 |
| 4 | 立ち上がり | 5px | 61 → 145 |
| 5 | 内側の明線 | 1px | 207 |
| — | 面 | 残り | 175–190 |

縁の帯の幅は **高さの10%**（135px高なら 13px）で固定します。

## 4. 光源

**315°（左上）で全部品固定。** これがばらつくと並べた瞬間に破綻します。

- 上端の縁が最も明るく、下端の縁が最も暗い
- 面の縦グラデも上が明るく下が暗い
- 内側の明るいベベル（層4）は上端で最も強く、下端では弱める

## 5. 金属のグラデーション停止点

`art/art-bible.md` の実測から。金リムに使います。

```
0%   #FFFFD8   外側の鏡面
18%  #EBBB92
34%  #AC6E38
50%  #653612   暗い縁取り帯
66%  #946843
82%  #D8A677
100% #F9C691   内側
```

面の色は部品ごとに `art/specs/ui-frames.md` を参照してください。

## 6. 状態

**別ファイルにせず、1つのSVGの中にレイヤーとして持たせてください。**
CSSから `opacity` / `display` で切り替えます。必須のID:

| ID | 内容 |
|---|---|
| `#rim` | 縁の5層すべて |
| `#face` | 面 |
| `#gloss` | 面の上の光沢（押下時に消す） |
| `#press` | 押下時に足す内側の影（既定 `opacity:0`） |

無効状態はCSSの `filter:saturate(.25) brightness(.7)` で作るので、SVG側では不要です。
