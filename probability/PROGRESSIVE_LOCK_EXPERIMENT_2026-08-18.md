# 段階固定4→4 確率実験計画

状態: **EXPERIMENT SPEC / 結果未算出**

## 比較する3条件

1. `free`: 現行。最終時点で31枚から自由に14枚。
2. `lock8_flop`: 共通15公開後に8枚を一括固定。
3. `lock4_4`: 共通15公開後に4枚、共通19枚時点でさらに4枚固定。

全条件で136牌、6人、私牌8、共通15＋4＋4、最終14、同じdeal seedを使用する。

## 固定方針

最初はproductionの5方針を流用する。

- 総合
- 順子系
- 七対子系
- 刻子系
- 染め系

各方針は、現在見えている情報だけで固定牌を決める。将来の＋4を覗かない。これを破ると固定ルールの不利益を過小評価する。

## 必須指標

| 指標 | 意味 |
|---|---|
| final completion | 固定後も完成14枚が存在するか |
| lock regret | 自由なら完成するが、固定が原因で完成不能になった率 |
| split pot | 同点POTの割合 |
| route share | 勝者が七対子・順子・刻子・染めへ偏っていないか |
| private attribution | 最終14枚に私牌を何枚使ったか |
| shared-core collision | 複数人が同じ共通牌の組を固定した率 |
| route pivot | フロップ方針と最終勝利ルートが変わった率 |
| street equity movement | ＋4ごとに勝率順位が動いた率 |

## 初期合格帯

- 最終完成率: 75〜92%
- 同点POT: 12%以下を目標、まず現行26.34%より明確に低下
- 最大勝利ルート: 40%以下
- 固定後悔率: 20%以下
- 私牌由来: 平均3枚以上

これは採用値ではなく、比較を止めないための初期ゲートである。
