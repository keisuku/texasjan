## 結論

旧V2の「押したくなる高揚感」を主軸に、Cleanの簡潔さ、現代日本プレミアム、キャラクターの感情、工芸素材を限定的に統合する。画面数と常時演出は増やさない。

## この方向で進める

| 画面 | 判断と次の処理 |
|---|---|
| タイトル・開始画面 | 雰囲気を主軸として保持する。 |
| キャラクターロビー | かなり良い。Gate Bの中心にする。 |
| モード選択 | テンションが上がり押したくなる性質を保持する。 |
| キャラクター一覧 | 構造と方向性を保持し、画質とキャラクター品質を作り直す。 |
| 着せ替え | ページの雰囲気を保持し、卓は再設計する。 |
| 4枚公開 | 洗練と面白そうな可能性を強演出の基準にする。 |

## 良い部分だけ使う

| 画面・方向 | 使う部分／変更点 |
|---|---|
| 対局画面 | シンプルな美しさ。通常時の情報階層へ使う。 |
| ロビー画面 | 全体方向の参考。 |

| C｜キャラクター対決 | キャラクターの感情と対決感を局所利用する。 |
| D｜現代日本工芸 | 素材感を局所利用する。リアルさは抑える。 |

| 大会表 | 将来、十分なユーザー数がいる段階で検討する。 |
| 賭ける場面 | 雰囲気を通常対局へ取り込む。 |
| オールインの緊張 | ALL-IN演出だけ採用候補。 |

- 現行ガチャ結果（集約し、切り替えやすいタブ形式へ再設計）
- ショップ・シーズンパス
- ランク進行
- ミッション・イベント

## Gate B 合成規則

1. タイトル、ロビー、モード選択は高揚感を優先する。
2. キャラクター一覧は構造を残すが、キャラクターと解像品質を作り直す。
3. 通常対局はCleanの簡潔さを継承する。
4. 強演出は4枚公開、ALL-IN、アガリ・勝利に限定する。
5. Aのプレミアム感とDの工芸素材は局所的に使う。
6. キャラクター詳細、着せ替え、ガチャ結果は集約・タブ化する。
7. 画面数を増やす提案には、維持管理上の明確な利益を要求する。
8. B/E、中国的記号、全画面細密装飾、常時発光、均一な過剰シャープネスを避ける。
