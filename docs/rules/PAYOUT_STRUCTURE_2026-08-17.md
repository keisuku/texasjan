# POTと2位賞金の客観検証

日付: 2026-08-17

## 結論

各局のPOTは1位総取りを維持し、完全同点だけ分割する。2位賞金を入れるなら、複数局を終えた試合全体の最終順位へだけ入れる。最初の比較候補は85% / 15%。

## 各局で2位へ配るとFOLDが壊れる

最終POTをP、CALL額をC、1位率をw、1位配分をα、2位配分をβとすると、CALLに必要な1位率は次式になる。

w >= (C / P - β) / (α - β)

元POT100に相手が50を賭け、こちらが50をCALLする例では最終POTは200。

| POT配分 | CALLに必要な1位率 |
|---:|---:|
| 100 / 0 | 25.0% |
| 90 / 10 | 18.8% |
| 85 / 15 | 14.3% |
| 80 / 20 | 8.3% |
| 70 / 30 | 0% |

70/30では負けても60を受け取れるため、50をCALLしても10増える。勝率ゼロでもFOLDしない方が得になり、ブラフと降りる判断が崩れる。

## 試合全体なら85 / 15が有力

6人が同額1単位を持ち寄る場合:

| 最終賞金 | 1位受取 | 2位受取 | 2位の参加費差引 |
|---:|---:|---:|---:|
| 85 / 15 | 5.1 | 0.9 | -0.1 |
| 80 / 20 | 4.8 | 1.2 | +0.2 |
| 70 / 30 | 4.2 | 1.8 | +0.8 |

85/15は2位だけでは参加費を回収できず、どこかで1位を取りに行く必要がある。80/20以上は生存だけを狙う戦略が黒字化しやすい。

## 推奨ルール

1. 各局POTは1位総取り。
2. 完全同点だけ等分。
3. オールインはメインPOTとサイドPOTを使う。
4. 複数局終了時の最終チップ量で1位・2位を決める。
5. 最終賞金だけ85 / 15を第一候補として検証する。
6. 時計回りのアンティ負担により、待つだけの戦略にもコストを持たせる。

## 固定seedで比較する戦略

- 常時ALL-IN
- 生存最優先
- 常時CALL寄り
- ランダム
- 1位確率を使う標準AI
- 1位・2位確率と期待値を使う適応AI

合格条件は、常時ALL-INと生存最優先のROIがともにマイナスで、標準AIが95%信頼区間で両者を上回り、低エクイティALL-INが100/0比で急増しないこと。

参考: PokerStarsの通常ショーダウンは最良ハンドがPOTを獲得し、Hi/Loは1位・2位ではなく別勝利条件を分ける。複数順位の賞金は各局POTではなくトーナメント最終順位へ支払われる。
