# Claude Opus 5へ最初に渡すプロンプト

このフォルダの `START_HERE.md` と `ASSET_MANIFEST.json` を最初に全文読んでください。

目的は、`visual/golden-target.webp` の見た目を再現しながら、既存のゲームロジックを本物のUIとして動かすことです。最初に実装する操作は一つだけです。

> 共通牌または私牌をタップすると、同じ牌が最下部の最終14枚へ追加され、元牌は薄くなる。最終手牌をタップすると解除される。

ドラッグ・牌の自由移動・画像全体への透明ボタン重ねは不要です。

`visual/arena-with-characters.webp` を最初の固定背景に使い、前景にPOT、席、共通15枚、+4×3、私牌8枚、最終14枚、おすすめ、クリア、FOLD/CALL/RAISEを配置してください。牌の34種レンダラーと既存ロジックは `source/current-playable-reference.html` から再利用できます。

まず `START_HERE.md` の「最初の提出物」8項目だけを実装してください。大きな配置・比率・技術方針を変更したくなった場合は、コードを書く前に理由と画面への影響を説明して承認を求めてください。

完成と自己判断せず、941×1672で `visual/golden-target.webp` とスクリーンショット比較できる状態で提出してください。
