# MAHJONG HOLD'EM — Character Art Audition R6

This gate returns to the successful `audition-r5` method.

## What is fixed

- the same three representative character identities;
- A/B/C ordering, clothing categories and pose logic;
- one readable full-body game sprite plus one highly detailed battle portrait;
- pale neutral audition-sheet composition.

## What is compared

- line language;
- face construction and age impression;
- paint and texture;
- body proportions;
- the contrast between ordinary gameplay art and the high-detail battle face.

Character setting, final costume, game-screen layout, table, UI and world background are deliberately outside this gate.

## Process after selection

1. Select one primary art language and at most one secondary source of elements.
2. Explore many genuinely different character archetypes inside that art language.
3. Test the selected cast at actual in-game portrait sizes.
4. Only then translate the approved art language into lobby, match, reveal, all-in and result screens.
